# Не сегодня

Пиксельная браузерная игра-погоня по зимнему Харькову. Ты убегаешь от ТЦК к метро и должен добраться до станции раньше, чем тебя поймают. Можно играть одному или вдвоём на одной клавиатуре.

Вся игра — один файл `index.html` (HTML + JS), без сборки и зависимостей.

## Управление

| Действие | Игрок 1 | Игрок 2 |
|---|---|---|
| Движение | W A S D | Стрелки |
| Рывок / вырываться при поимке | Пробел | Enter |
| Отвлечь преследователей | Q | Правый Shift |

## Рекорды

Общая таблица рекордов работает только в версии на claude.ai. На Render (и при открытии файла локально) рекорды хранятся в браузере игрока и у других людей не видны.

## Запуск локально

Просто откройте `index.html` в браузере.

## Размещение на Render (бесплатно) — для новичков

### Шаг 1. Репозиторий на GitHub

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **New repository**, имя например `ne-segodnya`, видимость Public (или Private), **без** README/.gitignore/лицензии (они уже есть в папке). Нажмите **Create repository**.

### Шаг 2. Залить файлы

**Вариант А: через git в PowerShell** (нужен установленный Git):

```powershell
cd D:\NeSegodnya
git init -b main          # если репозиторий ещё не создан
git add .
git commit -m "Первая версия игры"
git remote add origin https://github.com/ВАШ_ЛОГИН/ne-segodnya.git
git push -u origin main
```

При первом push откроется окно входа в GitHub.

**Вариант Б: через сайт GitHub** (без git):

1. Откройте созданный репозиторий, нажмите **uploading an existing file** (или **Add file → Upload files**).
2. Перетащите `index.html`, `render.yaml`, `README.md`, `.gitignore`.
3. Нажмите **Commit changes**.

### Шаг 3. Подключить Render

1. Зарегистрируйтесь на https://render.com (можно через GitHub) и разрешите доступ к репозиторию.
2. Вариант 1 — вручную: **New → Static Site**, выберите репозиторий, затем:
   - Branch: `main`
   - Build Command: оставьте пустым
   - Publish Directory: `.`
   - План: бесплатный (Free)
   - Нажмите **Create Static Site**.
3. Вариант 2 — по файлу: **New → Blueprint**, выберите репозиторий, Render прочитает `render.yaml` сам. Нажмите **Apply**.
   (Если Blueprint потребует платёжную карту, используйте вариант 1.)
4. Через минуту-две появится адрес вида `https://ne-segodnya.onrender.com` — это ссылка на игру.

### Как обновлять

Измените файлы, затем:

```powershell
cd D:\NeSegodnya
git add .
git commit -m "Что изменил"
git push
```

Render сам заметит push и выложит новую версию (автодеплой). Через сайт GitHub: откройте файл, нажмите карандаш, правьте и **Commit changes**; или снова загрузите файл через Upload files.
